## Stop-/Pivot-Kriterien
- Zweimal No-Go am Proof-Meilenstein → Grundsatzgespräch übers Format.
- Längere Zeit kein abgeschlossenes Paket → bewusste, dokumentierte Pause oder Pivot.
- Ein Paket dauert ein Mehrfaches der Erwartung → Retro vorziehen.
